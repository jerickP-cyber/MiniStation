# 🌦️ MiniStation

> A simple and modern web application for checking **real-time weather information** by location.

<p align="center">
  <a href="https://mini-station-livid.vercel.app">
    <strong>🌐 Live Demo</strong>
  </a>
</p>

---

## ✨ Features

* 🌤️ **Weather Updates** — View current weather information.
* 📍 **Location Search** — Search weather by location.
* 🗺️ **Interactive Map** — Explore locations visually.
* 📱 **Responsive Design** — Works across desktop and mobile screens.
* ⚡ **Fast & Lightweight** — Built with a simple and efficient web architecture.
